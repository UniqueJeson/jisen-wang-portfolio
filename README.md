# 王纪森 / Jisen Wang · 个人网站

首版为可直接部署的静态网站，默认中文，支持中英文切换并记住选择。无需安装依赖或构建。

## 在线访问

GitHub Pages 发布地址：<https://uniquejeson.github.io/jisen-wang-portfolio/>（启用 Pages 后生效）

## 本地预览

直接在浏览器打开 `index.html`，或运行 `start-preview.ps1` 后访问 `http://127.0.0.1:4186/`。

## 内容来源和边界

资料以本次用户确认、网站内中文简历及工作区现有项目材料为依据。
首页没有补写未经确认的现居城市、GitHub、LinkedIn 或证书。

课程项目为研究摘要，投资组合结果同时展示风险和限制；未声称所有团队工作均为个人独立完成，也未发布团队原始数据或整份作业。
无已确认奖项、用户量、商业效果或评价数据，因此未添加这些数字。

## GitHub Pages 部署

仓库设置中选择 **Settings → Pages → Deploy from a branch**，分支选择 `main`，目录选择 `/ (root)` 并保存。部署完成后可从 Pages 设置页打开站点。

仓库只需包含 `index.html`、`styles.css`、`app.js`、`assets/` 和本说明文件；测试截图与工作资料不属于网站发布内容。
